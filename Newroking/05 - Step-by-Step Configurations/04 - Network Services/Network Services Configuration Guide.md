# Network Services Configuration Guide

Complete these notes in order. Each guide includes a topology, addressing plan, exact device configuration, verification, testing, and troubleshooting.

1. [[19 - DHCP - Dynamic Host Configuration Protocol on a Cisco Router - Step by Step]] — Configure a Cisco router as a Dynamic Host Configuration Protocol (DHCP) server for VLANs 10 and 20, including excluded addresses and Domain Name System (DNS) settings.
2. [[20 - Central DHCP Server with DHCP Relay - Step by Step]] — Serve clients in multiple VLANs from a dedicated Packet Tracer DHCP server at 200.100.10.5 by using DHCP relay on each gateway.
3. [[21 - DNS - Domain Name System Server - Step by Step]] — Configure a Packet Tracer Domain Name System (DNS) server and resolve a web-server name from a client.
4. [[22 - NTP - Network Time Protocol - Step by Step]] — Synchronise Cisco routers and switches to a Packet Tracer Network Time Protocol (NTP) server and verify clock state.
5. [[23 - FTP and TFTP File Services - Step by Step]] — Configure Packet Tracer File Transfer Protocol (FTP) and Trivial File Transfer Protocol (TFTP) services, test user authentication, and transfer router files.
6. [[24 - HTTP, HTTPS, SMTP, POP3, and IMAP Services - Step by Step]] — Configure Packet Tracer web and email services, publish a web page, create user mailboxes, and test name-based client access.
