# Routing Protocols Configuration Guide

Complete these notes in order. Each guide includes a topology, addressing plan, exact device configuration, verification, testing, and troubleshooting.

1. [[14 - IPv4 - Internet Protocol Version 4 Static, Default, and Floating Static Routing - Step by Step]] — Connect three IPv4 networks with static routes, add an edge default route, and configure a higher-distance floating backup route.
2. [[15 - RIPv2 - Routing Information Protocol Version 2 - Step by Step]] — Exchange two LAN routes dynamically with Routing Information Protocol Version 2 (RIPv2), disable classful summarisation, and verify learned routes.
3. [[16 - OSPF - Open Shortest Path First Single-Area Configuration - Step by Step]] — Form an Open Shortest Path First (OSPF) adjacency in area 0 and advertise both LANs with correct wildcard masks.
4. [[17 - OSPF - Open Shortest Path First Multi-Area Configuration - Step by Step]] — Create a three-router OSPF design with backbone area 0 and two non-backbone areas connected through Area Border Routers (ABRs).
5. [[18 - EIGRP - Enhanced Interior Gateway Routing Protocol - Step by Step]] — Form an Enhanced Interior Gateway Routing Protocol (EIGRP) adjacency in autonomous system 100 and advertise two LANs without automatic summarisation.
