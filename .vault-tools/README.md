# Vault maintenance tools

- `organize_user_friendly.py` refreshes the current five-entry dashboards and subject guides.
- `archive/legacy_21_folder_builder.py` is retained only as a recovery record of the original bulk build. Do not run it against the current vault because it targets the superseded 21-folder layout.

The active Obsidian structure is documented in `Newroking/00 - Start Here/Vault Guide.md`.
