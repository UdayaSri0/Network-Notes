# Networking Learning Roadmap

> [!abstract]
> Recommended progression from first principles to integrated enterprise troubleshooting.

```mermaid
flowchart LR
F[Fundamentals] --> A[Addressing] --> S[Switching] --> R[Routing] --> N[Services] --> SEC[Security] --> HA[High Availability] --> M[Management] --> ADV[Advanced] --> T[Troubleshooting]
```

## Stage 1 - Fundamentals

1. [[OSI Model]]
2. [[TCP-IP Model]]
3. [[Ethernet]]
4. [[MAC Addressing]]
5. [[ARP - Address Resolution Protocol]]
6. [[IPv4 - Internet Protocol Version 4 Addressing]]
7. [[ICMP - Internet Control Message Protocol]]
8. [[TCP - Transmission Control Protocol]]
9. [[UDP - User Datagram Protocol]]

## Stage 2 - Addressing

10. [[Subnet Mask]]
11. [[Subnetting Basics]]
12. [[CIDR - Classless Inter-Domain Routing]]
13. [[VLSM - Variable Length Subnet Masking]]

## Stage 3 - Switching

14. [[VLAN - Virtual Local Area Network]]
15. [[VLAN Configuration]]
16. [[802.1Q Trunking]]
17. [[STP - Spanning Tree Protocol]]
18. [[RSTP - Rapid Spanning Tree Protocol]]
19. [[EtherChannel]]

## Stage 4 - Routing

20. [[Router on a Stick]]
21. [[Static Routing]]
22. [[RIP - Routing Information Protocol]]
23. [[OSPF - Open Shortest Path First]]
24. [[EIGRP - Enhanced Interior Gateway Routing Protocol]]

## Stage 5 - Services

25. [[DHCP - Dynamic Host Configuration Protocol]]
26. [[DNS - Domain Name System]]
27. [[NTP - Network Time Protocol]]
28. [[FTP - File Transfer Protocol]] and [[TFTP - Trivial File Transfer Protocol]]
29. [[HTTP - Hypertext Transfer Protocol]] and [[HTTPS - Hypertext Transfer Protocol Secure]]

## Stage 6 - Security

30. [[SSH - Secure Shell]]

32. [[ACL - Access Control List]]
33. [[Switch Port Security]]
34. [[DHCP Snooping]]
35. [[Dynamic ARP Inspection]]
36. [[NAT - Network Address Translation]]

## Stage 7 - High Availability

37. [[HSRP - Hot Standby Router Protocol]]
38. [[VRRP - Virtual Router Redundancy Protocol]]
39. [[EtherChannel]] redundancy

## Stage 8 - Management

40. [[SNMP - Simple Network Management Protocol]]
41. [[Syslog]]
42. [[CDP - Cisco Discovery Protocol]]
43. [[LLDP - Link Layer Discovery Protocol]]
44. [[Wireshark]]

## Stage 9 - Advanced

45. [[IPv6 - Internet Protocol Version 6]]
