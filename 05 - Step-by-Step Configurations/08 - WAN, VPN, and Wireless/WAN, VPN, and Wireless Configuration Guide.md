# WAN, VPN, and Wireless Configuration Guide

Complete these notes in order. Each guide includes a topology, addressing plan, exact device configuration, verification, testing, and troubleshooting.

1. [[37 - GRE - Generic Routing Encapsulation Tunnel - Step by Step]] — Build a Generic Routing Encapsulation (GRE) tunnel between two routers, route private LAN traffic through it, and verify tunnel reachability.
2. [[38 - PPP with PAP and CHAP - Point-to-Point Protocol Authentication - Step by Step]] — Configure a serial Point-to-Point Protocol (PPP) link and test Password Authentication Protocol (PAP) and Challenge Handshake Authentication Protocol (CHAP) as separate authentication methods.
3. [[39 - IPsec - Internet Protocol Security Site-to-Site VPN - Step by Step]] — Protect traffic between two private LANs with an Internet Protocol Security (IPsec) site-to-site virtual private network using an Internet Key Exchange policy, transform set, crypto ACL, and crypto map.
4. [[40 - WPA2 - Wi-Fi Protected Access 2 Wireless LAN - Step by Step]] — Create a secured wireless local area network with a service set identifier (SSID), Wi-Fi Protected Access 2 (WPA2) pre-shared key, DHCP, and client association.
