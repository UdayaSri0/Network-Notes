# High Availability Configuration Guide

Complete these notes in order. Each guide includes a topology, addressing plan, exact device configuration, verification, testing, and troubleshooting.

1. [[31 - HSRP - Hot Standby Router Protocol with Tracking - Step by Step]] — Provide a resilient virtual default gateway with Hot Standby Router Protocol (HSRP), deterministic active/standby roles, preemption, and uplink tracking.
2. [[32 - VRRP - Virtual Router Redundancy Protocol - Step by Step]] — Configure Virtual Router Redundancy Protocol (VRRP) with a master, backup, virtual address, and preemption where the selected IOS image supports it.
3. [[32A - GLBP - Gateway Load Balancing Protocol - Step by Step]] — Configure Gateway Load Balancing Protocol (GLBP) so two routers provide one resilient virtual gateway while sharing client forwarding responsibility.
